# Verification Methodology

1. Compare AI response with course material.
2. Compare with textbooks or handouts.
3. Check examples manually.
4. Verify calculations independently.
5. Reject unsupported claims.

---

# Observations

Advantages:
- Faster understanding of concepts.
- Helpful for examples and summaries.
- Useful for code generation.

Limitations:
- Occasionally lacks context.
- Requires human verification.
- May generate incomplete examples.

---

# Conclusion

AI can assist learning and productivity but should not replace independent verification using textbooks, official handouts, practical testing, and instructor guidance.
